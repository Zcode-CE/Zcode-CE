# 侧边面板全视图（CE 版）

## 1. 范围

把右侧面板临时铺满「对话区 + 面板」的全部内容宽度，对话区仍挂载在原位（不卸载、不重建
SessionPane），只是被面板覆盖；左侧任务列表、窗口控制按钮、侧栏开合保持不变。

**本版不做**（与上游 3.16.2 的差异）：对话 tab、浮动输入窗、最小化圆形按钮、抢答气泡、
面板级拖拽吸附、拆分 pane 入口下线。这些需要把 composer 从对话 DOM 里投影到浮窗，属于独立
的布局 owner 改造；本版只保证「面板全宽查看 + 原样退出」。

## 2. 入口与退出

| 动作                                                   | 结果                                         |
| ------------------------------------------------------ | -------------------------------------------- |
| 面板顶栏「全视图」按钮 / `Ctrl+Shift+F`（macOS `⌘⇧F`） | 进入；面板铺满内容区，按钮变为「退出全视图」 |
| 同一按钮 / 同一快捷键                                  | 退出；恢复原三栏布局与既有面板宽度           |
| 关闭面板（◫）                                          | 退出（面板已不可见）                         |
| 关闭最后一个面板 tab                                   | 面板按既有规则收起，随之退出                 |
| 切换任务 / 草稿 owner                                  | 退出（全视图按 owner 记忆，不跨任务沿用）    |

- 快捷键只在桌面端注册（Web/手机不抢 `Ctrl+Shift+F`）。
- 退出不修改侧栏显隐、侧栏宽度、终端开合、面板宽度等任何既有状态。

## 3. 实现要点

- 全视图 = 面板的 `ResizablePanel` 改为 `absolute inset-0`（父 `PanelGroup` 为定位容器），
  对话列仍在 flex 流里保持原尺寸，只是被覆盖；`ResizeHandle` 同时隐藏。
- 不改 `useAnimatedResizablePanel` 的尺寸记忆；退出后宽度沿用进入前的持久化布局。
- 对话区仍是同一个 `SessionPane` 实例：不移动 DOM、不复制 composer、不重新挂载。
- 面板关闭/owner 变化由 effect 收敛为「退出」，避免出现面板不可见但全视图状态残留。

## 4. 验证

- 自动化：组件源码级护栏（全视图按钮、快捷键注册、absolute 覆盖、退出复位、i18n 键）。
- 人工（未执行时不得声称通过）：桌面三平台进出全视图、快捷键、关闭面板/最后 tab 的退出、
  切换任务后的复位、全视图内拖拽 tab/浏览器 guest 的定位。
