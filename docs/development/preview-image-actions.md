# 图片预览操作：复制与下载（已实现）及后续

## 1. 范围

右侧预览的图片区域提供「复制图片」与「下载图片」：复制把当前预览的图片以 PNG 写入系统剪贴板
（保留自然像素与透明度；SVG/JPEG 先栅格化），下载保存预览读到的原始字节，不把 SVG 变成截图。

**当前实现**：复制图片（本机客户端剪贴板）、下载图片（原始字节，桌面另存为 / Web 浏览器下载）。
**未实现**（见 §5）：添加到聊天、右键菜单/窄屏菜单按钮。

## 2. 为什么这样做

- 复制不需要服务层或主进程参与：预览已经拿到可解码的图片，客户端 canvas 转 PNG 后写剪贴板即可；
  引入 IPC 只会多一条状态通道。
- 远端文件沿用既有预览数据链路，复制发生在查看图片的客户端；不引入 Agent 请求，不改变
  `workspaceIdentity`、desktop continuous 或 web remote replayable 的恢复边界。
- PNG 转换必须在用户操作内立即创建并提交 promise（`ClipboardItem` 接受 `Promise<Blob>`），
  避免异步转换先消耗 Safari 的用户激活权限。

## 3. 行为与边界

- 图片未加载完成、或本次复制未结束时按钮禁用。
- 成功显示「已复制图片」；解码失败、canvas 被跨域污染、剪贴板 API/权限不可用时显示失败提示，**不误报成功**。
- 只改右侧预览的展示层；不改变预览布局、Retina 显示规则、SVG 源码切换。
- 不扩展到全屏会话图片画廊。

## 4. 验证

| 编号   | 前提与动作                 | 断言                                                      |
| ------ | -------------------------- | --------------------------------------------------------- |
| PIC-01 | PNG 加载后复制             | 剪贴板为图片，像素尺寸与原图一致（需真实浏览器/桌面手测） |
| PIC-02 | SVG 预览后复制             | 剪贴板为 PNG，可粘贴为图片                                |
| PIC-04 | 加载中/解码失败/剪贴板拒绝 | 入口禁用或明确失败，不显示成功                            |

本仓库可自动验证的部分：类型检查、i18n 键在位、复制函数对 canvas/toBlob 失败的分支（单测）。
真实剪贴板读取（原生像素/权限拒绝）需要人工在桌面与手机浏览器执行，未执行时不得声称通过。

## 5. 未实现与后续

- **下载图片**（已实现）：保存预览读到的原始字节（SVG 下载为 `.svg`，不是截图）；扩展名按 MIME 对齐
  （png/apng/jpg/gif/webp/avif/bmp/ico/svg）；桌面走 `IPlatformService.saveFile` 另存为，取消静默，
  成功只提示「下载成功」不带路径；无 saveFile 的客户端退回浏览器下载并提示「已开始」。
- **添加到聊天**：复用文件树的 `dispatchWorkspaceFileAddToChat`，只追加文件 mention 并聚焦，不自动发送；
  远端 identity 与来源路径不匹配时禁用。
- **右键菜单与窄屏「图片操作」按钮**：当前只有一个复制按钮；菜单化需要同时覆盖键盘菜单与触屏。
